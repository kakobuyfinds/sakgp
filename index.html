From listing to parcel

Keep the seller’s URL and your chosen variant together so you can check both when the item reaches the warehouse.

  1. Check the seller link

    Open the item on HipoBuyFind and follow its purchase link to the seller. Confirm the exact option, stock, and size chart. Paste the seller URL into SuperBuy and check that the item and options load before ordering.

  2. Review warehouse photos

    Compare the photos with the option you ordered. For shoes, check the size label, outsole, and both shoes together. For clothing, check the color and ask whether measured chest width or length can be provided if sizing is uncertain.

  3. Estimate shipping

    Add the item price, domestic delivery, agent fees, and estimated international shipping. Compare available routes using the packed parcel’s weight and dimensions. If you are buying shoes, check how keeping the box changes the estimate.

SuperBuy spreadsheet FAQ

What is a SuperBuy spreadsheet?

It is a shopping directory that groups product finds so you can compare items and locate the seller links you may want to submit to SuperBuy.

What should I do if SuperBuy cannot open a link?

Reopen the original seller listing and confirm that the item and your variant are still available. If the listing opens but SuperBuy cannot import it, ask SuperBuy whether it supports that seller or accepts a manual order for the item.

Do the catalog prices include shipping?

They show the source item price with an approximate USD conversion. Check domestic delivery, fees, and international shipping separately before budgeting for the order.

Can I confirm size from a catalog photo?

Compare the seller’s size chart with a similar item you already own. If you receive warehouse photos, check the size label and request a measurement where the service offers it.
